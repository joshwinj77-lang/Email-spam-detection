# 📧 Email / SMS Spam Detection using Naive Bayes (Scikit-learn)

A simple Machine Learning project that classifies messages as **Spam** or **Ham (Not Spam)** using **CountVectorizer** and **Multinomial Naive Bayes**.

---

## 🚀 Technologies Used

- Python
- Scikit-learn
- CountVectorizer (Text → Numbers)
- Multinomial Naive Bayes (Classification)

---

## 📂 Dataset

Sample messages labeled as:
- `spam`
- `ham`

---

## 🧠 How It Works

1. Convert text messages into numeric vectors using **CountVectorizer**.
2. Split data into training and testing sets.
3. Train a **Naive Bayes** model on training data.
4. Test model accuracy.
5. Predict whether a user-entered message is spam or ham.
